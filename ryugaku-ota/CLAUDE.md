# 留学OTA（仮）— Claude Code への引き継ぎ

このリポジトリは、claude.ai のチャットで壁打ち・プロトタイプ作成・動画制作まで進めた内容を引き継いだものです。作業を始める前に、このファイルと `docs/` を読んでください。

## プロダクト
- 一言で：留学エージェントから独立した第三者として、海外の語学学校・大学のプランを航空券込みの総額で一覧比較でき、渡航までの残りステップを常に見ながら申し込める、Trip.com型の留学比較アプリ
- 対象ユーザー：海外に行ってみたい日本の大学生。エージェントを2〜3社またぐのが限界で比較しきれず、「この先何をすればいいかわからない」ことが不安
- 収益：学生は無料。渡航が決まった時点で学校から学費の20%をコミッションとして受け取る
- 検証したいこと（最重要）：渡航までに何ステップあって、あとどれくらいかが見え、手続きがシンプルに感じられれば、学生は面談なしで申し込みまで進むか

詳細は `docs/01_事業概要.md` を参照。

## 守ること
- スマホ（幅375px）を最優先。ボタンは高さ44px以上
- 文言はすべて日本語。押しつけず、学生に親しみやすい口調
- 「渡航まであと◯ステップ」のバーは全画面で常に表示する（検証の本命）
- 架空のデータであることがわかるようにする。写真の代わりのイラストには「イメージ」と表記する
