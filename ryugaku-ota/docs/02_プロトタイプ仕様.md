# プロトタイプ仕様

## 元の仕様プロンプト
次のWebアプリのプロトタイプを作ってください。スマホで開かれることを最優先にしてください。

### プロダクト
- 名前：留学OTA（仮）
- 一言で：留学エージェントから独立した第三者として、海外の語学学校・大学のプランを「航空券まで含めた総額」で一覧比較でき、渡航までの残りステップを常に見ながら申し込める、Trip.comのような留学比較アプリ
- 対象ユーザー：海外に行ってみたい大学生。スマホで初めて開く
- 検証したいこと：「渡航まであと◯ステップ」が常に見えている体験がいちばん安心で気持ちよくなるように作る

### 作る範囲
- 今回はバックエンドなし。データはlocalStorageに保存し、リロードしても翌日開いても消えないようにする
- 学校・プラン・口コミ・航空券の目安はモックデータ（src/data/）
- ログイン、決済、実際のビデオ通話、ホテル一覧、航空券のリアルタイム検索、通知は作らない
- AIチャットbotはモック応答で作り、後でLLMに差し替えられる構造にする

### 技術スタック
Vite + React + TypeScript / Tailwind CSS / shadcn/ui（Button、Card、Input、Dialog、Sheet、Slider、Badge、Tabs、Progress、Toast） / lucide-react / react-router-dom / date-fns

### データ設計（後でSupabaseに移す前提）
- 型は src/types.ts
- School：id, name, country, city, region_note, atmosphere, rating, review_count, image_url（＋ format, tags）
- Plan：id, school_id, course_name, course_type, weeks, tuition_jpy, stay_type, stay_cost_jpy, fees_jpy, activities[]（＋ requirement）
- FlightEstimate：id, city（または country）, round_trip_jpy, note
- Review：id, school_id, rating, body, author_label, created_at
- Application：id, user_id(string | null), plan_id, name, email, preferred_datetime, status('requested' | 'consulting' | 'contracted' | 'visa' | 'paid' | 'departed'), created_at
- 総額 = 学費 + 滞在費 + 諸費用 + 航空券の目安。内訳を必ず見せ、「目安」と明記する
- 保存と読み込みは src/lib/repository.ts に集約（listSchools / getSchool / listPlans / getFlightEstimate / listReviews / getCompareList / toggleCompare / createApplication / getCurrentApplication / getJourneyProgress。すべてPromise）
- AIは src/lib/assistant.ts の ask(schoolId, question)

### 画面
/ ホーム、/search 検索結果、/compare 比較、/schools/:id 学校詳細、AIチャット、/apply/:planId 申し込み、申し込み完了、/debug 検証用記録

## プロトタイプに後から加えた変更（現在のjsxが正）
1. 検索バーの改善：タップで「おすすめの探し方」と国一覧を表示。入力に応じて国・都市・学校・コース・環境の候補。ひらがな・ローマ字でも一致。「4週」「50万」を期間・予算として読み取る。検索結果の上に、次に絞ると選びやすい条件を提案。0件のときは外す条件をボタンで提案
2. 学校数：4か国（フィリピン・オーストラリア・カナダ・マルタ）に語学学校3校ずつ＋大学1校ずつ、計16校・32プラン
3. 留学形式：「語学留学／大学留学」を切り替え。大学は「1学期だけ留学」「学部正規入学」。出願条件（IELTS等）を表示
4. 学校の写真：写真の代わりに学校ごとのSVGイラスト（校舎・教室・滞在先）。「イメージ」と表記。本番は提携校から写真を提供してもらう
5. 相談日時：翌日から7日分、10:00〜20:00の1時間枠。埋まっている枠は選べない
6. 学生向けUI：下のタブメニュー（ホーム／さがす／くらべる／お気に入り／マイ留学）、30秒の行き先診断（3問）、お気に入り、マイ留学（残りステップ・次にやること・申し込み状況・準備チェックリスト）、1日の過ごし方（例）、国旗、丸ゴシック（M PLUS Rounded 1c）
